# Vercel Deployment Guide for Smart Supply PWA

## Prerequisites
1. Backend deployed on Vercel (or another platform)
2. Vercel account
3. GitHub repository

## Environment Variables

Set these in your Vercel project settings:

### Frontend (smartsupply) Environment Variables:
```
VITE_API_BASE_URL=https://your-backend-url.vercel.app/api
VITE_API_URL=https://your-backend-url.vercel.app
```

### Backend Environment Variables:
```
DATABASE_URL=your_database_connection_string
JWT_SECRET=your_jwt_secret_key
NODE_ENV=production
```

## Deployment Steps

### 1. Deploy Backend First
1. Deploy the `smart-BE` folder to Vercel
2. Note the backend URL (e.g., `https://smart-supply-backend.vercel.app`)

### 2. Deploy Frontend
1. Deploy the `smartsupply` folder to Vercel
2. Set environment variables in Vercel dashboard
3. Use the backend URL for API configuration

### 3. Configure CORS
Make sure your backend allows the frontend domain:
```javascript
const allowedOrigins = [
  'https://your-frontend-url.vercel.app',
  'http://localhost:8080', // for development
];
```

## PWA Features on Vercel

### Service Worker
- Automatically generated by Vite PWA plugin
- Cached at `/sw.js`
- Handles offline functionality

### Push Notifications
- Requires HTTPS (Vercel provides this)
- Service worker handles background notifications
- Works on mobile devices

### Installation
- Users can install from browser
- Appears in app drawer/home screen
- Runs in standalone mode

## Troubleshooting

### Common Issues:
1. **API Connection Failed**: Check environment variables
2. **WebSocket Not Connecting**: Verify backend URL
3. **PWA Not Installing**: Check manifest.json and service worker
4. **Push Notifications Not Working**: Verify HTTPS and service worker

### Debug Steps:
1. Check browser console for errors
2. Verify environment variables in Vercel
3. Test API endpoints directly
4. Check service worker registration

## Testing PWA Features

1. **Install App**: Look for "Add to Home Screen" prompt
2. **Offline Mode**: Disconnect internet and test functionality
3. **Push Notifications**: Send notification from admin panel
4. **Real-time Updates**: Test WebSocket connections

## Production Checklist

- [ ] Backend deployed and accessible
- [ ] Environment variables set correctly
- [ ] CORS configured for frontend domain
- [ ] HTTPS enabled (automatic on Vercel)
- [ ] Service worker registered
- [ ] Push notifications working
- [ ] PWA installable
- [ ] Offline functionality tested
